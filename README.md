# SalesLeague ⚡

Мотивационная игра для отдела продаж. Сотрудники зарабатывают выстрелы за продажи и стреляют по полю морского боя, выигрывая призы.

---

## Установка и запуск

### Шаг 1 — Установи Docker

Docker — это программа, которая запускает приложение. Нужно установить её один раз.

1. Перейди на сайт [https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop)
2. Скачай версию для своей ОС (Mac / Windows)
3. Установи как обычную программу
4. Запусти Docker Desktop — в трее появится иконка кита 🐳

> На Windows может потребоваться включить WSL2 — Docker сам предложит это сделать при первом запуске.

---

### Шаг 2 — Скачай приложение

Скачай архив с кодом и распакуй его в любую папку, например `C:\SalesLeague` или `~/SalesLeague`.

---

### Шаг 3 — Создай файл с настройками

Войди в папку с приложением. Найди файл `.env.example` и сделай его копию с именем `.env`.

**На Mac / Linux** — открой Терминал, перейди в папку и выполни:
```bash
cp .env.example .env
```

**На Windows** — в Проводнике скопируй файл `.env.example`, вставь рядом и переименуй копию в `.env`.

Открой файл `.env` любым текстовым редактором (Блокнот подойдёт) и замени значения на свои секретные слова:

```
JWT_SECRET=любой_набор_букв_и_цифр_подлиннее
JWT_REFRESH_SECRET=другой_набор_букв_и_цифр_подлиннее
```

> Эти строки — пароли для защиты сессий. Придумай любые, главное чтобы они были разными.

---

### Шаг 4 — Запусти приложение

Открой терминал (на Windows — PowerShell или Командная строка) в папке с приложением и выполни:

```bash
docker compose up -d
```

Docker скачает всё необходимое и запустит приложение. Первый запуск занимает 3–5 минут.

Когда увидишь `✔ Container ... Started` — всё готово.

---

### Шаг 5 — Создай первого администратора

Выполни эту команду в терминале (одной строкой):

```bash
docker compose exec api node -e "const {PrismaClient}=require('@prisma/client');const b=require('bcryptjs');const p=new PrismaClient();b.hash('admin123',10).then(h=>p.user.create({data:{name:'Admin',email:'admin@example.com',passwordHash:h,role:'ADMIN'}})).then(u=>{console.log('Готово! Логин:',u.email);p.\$disconnect()})"
```

В терминале появится `Готово! Логин: admin@example.com` — значит администратор создан.

---

### Шаг 6 — Открой приложение

Перейди в браузере на [http://localhost](http://localhost)

Войди с данными:
- **Email:** `admin@example.com`
- **Пароль:** `admin123`

Всё, приложение работает! 🎉

## Как пользоваться

### Администратор

1. **Создать сезон** — вкладка «Сезоны» → задай название и сумму за выстрел (₽)
2. **Активировать сезон** — нажми «Активировать», корабли расставятся автоматически
3. **Добавить сотрудников** — вкладка «Пользователи»
4. **Начислять продажи** — вкладка «Продажи» → выбери сотрудника и введи сумму, выстрелы начислятся автоматически

### Сотрудник

1. Открыть [http://localhost](http://localhost) и войти
2. На «Поле» кликать по клеткам — тратить выстрелы
3. «Рейтинг» — таблица лидеров

## Управление

Все команды выполняются в терминале из папки с приложением.

| Что сделать | Команда |
|---|---|
| Запустить | `docker compose up -d` |
| Остановить | `docker compose down` |
| Посмотреть логи | `docker compose logs -f` |
| Обновить после новой версии | `docker compose up -d --build` |

> ⚠️ Команда `docker compose down -v` удаляет базу данных вместе со всеми данными. Не используй её если не хочешь потерять данные.
